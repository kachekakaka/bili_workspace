## 1. 目标与完成结果

本方案不是要求每个页面都机械改写，而是把已确认的共享热点和高收益页面收口为一组可测量的改进：

1. 未变化的媒体索引不再产生全量深拷贝；
2. 同一会话中的等价读取请求可以复用最近成功结果并合并并发请求；
3. TaskStream 只在 Dashboard 或 Tasks 活动时存在，其他路由不保留任务实时连接；
4. Dashboard 使用不包含任务明细的轻量摘要实时流；
5. Dashboard、Library、Groups、Settings 和 Account 按各自一致性要求获得更快首屏；
6. Library 的选择和单项标签变化不再重建当前页全部卡片；
7. Search 保留现有取消旧请求、服务端缓存和空闲预取能力，同时让浏览器页缓存有固定上限；
8. 后台刷新失败时保留最近成功内容，明确显示“数据可能已过期”并提供重试，不把旧内容伪装成最新结果。

完成结果以请求次数、索引复制次数、实时连接数量、SSE 载荷形状和 DOM 节点身份等确定性证据证明，不以单机毫秒阈值作为主要门禁。

## 2. 已冻结事实与问题判定

### 2.1 既有任务页优化的边界

历史方案 TASKS-20260815 已实现队列变更计数、SSE 按变化推送和任务卡差量更新，并明确排除了其他页面、增量 payload 和虚拟滚动。本方案延续“先消除无效工作，再决定是否拆包”的路线。

TASK-CANCEL-20260823 已确认实际队列覆盖基类通知方法后没有递增变更计数，导致现有 SSE 优化在生产队列上失效。该缺陷必须先修复并通过独立验收，之后才能把实时流工作量结果作为本方案证据。

### 2.2 共享热点

- web/assets/app/main.mjs 在认证启动时读取 /api/status，随后管理员又读取 /api/groups；而 /api/status 已包含 group_records。
- Dashboard 和 Tasks 启动同一 TaskStream，但当前只在退出登录时停止，切到其他页面后连接仍然存在。
- /api/status、分组、Dashboard 和 Library 等路径会触发 Nas.sync_index。
- Nas.sync_index 当前先调用 IndexStore.snapshot，再比较 change token；因此索引未变化时仍会深拷贝全部条目。
- Dashboard 等待摘要和最近作品两个请求后才提交首屏，并消费完整任务列表流只为显示四个计数。

### 2.3 页面现状

- Library 已有服务端分页和封面懒加载；高收益点是查询页复用以及选择、标签操作的局部 DOM 更新。
- Search 已有旧请求中止、服务端缓存和下一页空闲预取；主要残余问题是模块级 Map 可无界增长。
- Groups 与 Settings 重复读取启动阶段已经获得的数据。
- Account 每次进入都阻塞等待 refresh_login=true 的强校验。
- Users 数据量小且权限敏感，必须保持进入页面即读取最新数据。
- Download 与 More 以静态交互为主，没有足以抵偿复杂度的页面专属热点。
- 所有页面模块目前静态导入；动态路由加载和二维码模块延迟加载留待第一波优化后的测量结果决定。

## 3. 目标契约

### 3.1 会话级读取缓存

新增一个只存在于当前认证会话内的资源缓存，契约固定如下：

1. 缓存不写 localStorage、sessionStorage、数据库或服务端，不跨账号复用；登出、认证失效和重新登录时完整清空。
2. key 由资源名和规范化查询参数构成；用户角色或账号上下文发生变化时不得命中旧账号结果。
3. 同一 key 同时最多存在一个在途读取请求，后续消费者复用同一 Promise。
4. 在途请求及其 AbortController 由资源缓存拥有，不使用任一页面的路由 signal 作为共享 fetch signal。页面退出只取消该消费者的提交和订阅，不得中止其他消费者复用的 Promise。
5. 只有登出、认证失效、缓存整体清理或显式失效该 key 时才中止缓存拥有的在途请求；中止后必须移除 in-flight 记录，后续请求可以重新发起。
6. 有最近成功结果时，页面先渲染该结果，再在路由进入后后台校验；没有结果时继续显示明确加载状态。
7. 后台校验成功后原子替换缓存并只更新仍活动的路由；旧路由响应不得覆盖当前页面。
8. 后台校验失败时保留最近成功结果，页面显示“数据可能已过期”和重试动作；没有成功结果时仍显示正常错误。
9. 顶部手动刷新绕过最近结果、合并同轮等价请求，并按资源关系刷新；刷新失败不清除最后成功数据。
10. 写操作成功后按影响域显式更新或失效，不依赖固定 TTL 推断正确性。

明确失效关系：

- 分组创建、修改、合并或删除：失效 groups、status.group_records、Library 查询页和 Dashboard 摘要；
- 媒体移动、删除或批量标签：局部更新当前可确认记录，同时失效受影响的 Library 查询页和 Dashboard 数据；
- 配置保存：失效 status，config 下次读取仍保持强制新鲜；
- Bilibili 登录状态变更：失效 status，并立即更新顶部状态标记；
- 新建、重试或取消任务：由任务实时流负责活动状态，涉及媒体落库的终态再失效 Library 和 Dashboard 数据。

### 3.2 TaskStream 生命周期与载荷

1. TaskStream 使用页面租约或等价引用计数；Dashboard 和 Tasks 在 mount 时获取，在 dispose 时释放。
2. 没有活动租约时关闭 EventSource；其他页面不得保持 /api/events 连接。
3. Tasks 使用默认完整模式，保持现有任务列表和 summary 兼容载荷。
4. Dashboard 使用 /api/events?view=summary；事件仍为 tasks，但 data 只包含 summary 和 at，不包含 tasks 明细。
5. 服务端 summary 模式直接聚合当前用户可见任务状态，不先构造、装饰和序列化任务明细。
6. full 与 summary 使用隔离快照。summary 的 get/subscribe 结果不得通过 reducer 回退保留旧 full.tasks 或 grouped；切入 summary 时清除任务明细，切回 full 时等待完整首帧或任务页显式 reload，不把旧 full 快照冒充当前数据。
7. 同一页面租约重复获取不产生重复 EventSource；模式切换先关闭旧连接、隔离旧事件，再创建新连接。租约释放函数可重复调用且只释放自身。
8. 认证心跳、断线重连和登出清理保持现有安全语义；登出同时清除两种模式快照。

### 3.3 媒体索引同步

IndexStore 增加原子“仅在 token 变化时复制”的读取能力：

- 一次加锁内刷新外部变化、返回 token 与条目数；
- token 与调用方上一 token 相同时返回无条目快照，禁止 deepcopy；
- token 变化时只产生一次一致快照；
- 现有 snapshot 和 change_token 的公开行为保持兼容。

Nas.sync_index 使用该能力。未变化分支保持现有结果字段，但 imported、skipped、removed 为 0，unchanged 使用不复制条目的计数；变化分支继续执行现有校验、导入、修补和删除逻辑。

### 3.4 页面实施矩阵

| 页面或层级 | 本轮行为 | 一致性边界 |
| --- | --- | --- |
| Shared | 资源缓存、请求合并、显式失效；从 /api/status.group_records 复用分组 | 会话隔离；手动刷新可强制校验 |
| Dashboard | 缓存首屏、后台刷新、摘要专用实时流 | 旧数据必须标记；实时任务只传 summary |
| Library | 缓存规范化查询页；选择、单项标签和可确认写操作局部更新 | 服务端分页保持 36；删除、移动等影响排序的操作失效相关页 |
| Search | 保持既有路径；缓存改为最多 24 项的 LRU | fresh 请求绕过缓存；预取也受同一上限 |
| Groups | 先显示 shared 分组，再后台校验 | 所有分组写操作显式失效关联资源 |
| Settings | 复用 shared status，/api/config 每次进入强制读取 | 配置提交后失效 status，不缓存敏感配置响应 |
| Account | 先显示最近 status，后台执行 refresh_login=true | 二维码和登录动作仍读取最新状态；失败显示旧状态标记 |
| Users | 不缓存，进入即读取最新数据 | 用户、角色、禁用和会话状态始终权威 |
| Download、More | 不做页面专属性能改写 | 继续消费必要的 shared 数据 |

## 8. 风险、停点与回退

- 旧数据误导：任何缓存命中后的刷新失败都必须显式标记，不允许静默显示为最新。
- 跨账号泄漏：资源缓存只能属于认证会话；会话切换清理失败视为阻断缺陷。
- 共享请求误取消：路由 signal 只约束消费者提交，不能成为共享 fetch 的所有者；登出、认证失效和显式失效必须反向确认能够终止缓存自有请求。
- 失效遗漏：新增写操作消费者或无法确定影响域时停止，不用短 TTL 掩盖。
- 实时流重复：租约或模式切换出现两个活动 EventSource 时验证失败。
- 模式快照污染：summary 不得保留 full.tasks/grouped，full 也不得把 summary 快照冒充任务列表首帧。
- DOM 局部更新错误：排序、筛选或分页成员关系变化时允许失效并重新取页，不强行局部修补。
