# 软件测试

本文件只保存稳定的活动测试项 Registry。Registry 不登记 CI 并行阶段、固定用例清单或单次运行；动态结果由控制台、CI Artifact 或对应平台的最小交接记录承接。

| ID | 执行类别 | 入口 | 唯一职责 |
| --- | --- | --- | --- |
| T-DOC | full | [文档机械门禁](../SoftwareTesting/doc_consistency/README.md) | 检查文档骨架机械一致性 |
| T-ARCHIVE | affected_only | [归档机械门禁](../SoftwareTesting/archive_consistency/README.md) | 检查完整归档区的索引与正文一一登记 |
| T-PROJECT | full | [项目完整自检](../SoftwareTesting/project/README.md) | 执行项目现有源码、Python、Node 与 Playwright 测试入口 |
| T-DOCKER | affected_only | [Docker 镜像构建验证](../SoftwareTesting/docker/README.md) | 验证当前 Docker 镜像的实际构建、架构范围与不发布边界 |
| T-LAUNCHER | affected_only | [Windows 启动器测试](../SoftwareTesting/launcher/README.md) | 验证数据根、网络安全、进程所有权、离线资源、GUI、单文件候选与固定 amd64 Docker 导出协议 |
| T-BILIBILI-LIVE | affected_only | [真实 Bilibili 影响域验证](../SoftwareTesting/bilibili_live/README.md) | 在显式单标记授权下，先于相关模拟测试验证真实登录、发现、封面及受影响的有界下载、页面或候选 EXE 成功链 |
