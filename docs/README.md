# bili_workspace 文档索引

本页是活动文档总入口，只承接职责索引、事实分流、生命周期、条件专题和归档入口。产品与实现事实由对应活动真源承接，版本历史摘要由 [`CHANGELOG.md`](../CHANGELOG.md) 承接。

## 核心文档

- [需求文档](需求文档.md)：用户可观察行为与支持边界的唯一当前真源
- [设计文档](设计文档.md)：实现结构、调用链和数据流的唯一当前真源
- [已知问题与待做需求](已知问题与待做需求.md)：尚未完成事项及活动方案入口
- [软件测试 Registry](软件测试.md)：活动测试项与执行类别

## 条件专题

- [字段契约](字段契约.md)：存在数据库、API、配置和跨进程序列化边界，承接字段名称、默认值、所有权和兼容规则
- [架构决策入口](设计文档.md#架构决策)：当前有效 ADR 由设计文档链接并说明适用关系
- [部署、网络、备份、恢复、源码更新与回滚入口](运维/README.md)

## 文档生命周期

- **长期当前真源**：需求、设计、字段契约、待办和测试 Registry 持续承接各自当前职责；建立新的承接和入口前，不得让旧真源退出活动区。
- **当前可执行手册**：`docs/运维/` 只保留当前仍受支持的部署、更新、恢复和故障处理流程；流程被替代或不再支持时，先更新当前承接和入口，再转入历史归档。
- **ADR**：当前有效决策由[设计文档](设计文档.md)链接。决策被替代时，先让当前设计链接新决策并说明替代关系，再将只剩历史职责的旧记录归档。
- **活动待办与方案**：未完成事项只登记在[已知问题与待做需求](已知问题与待做需求.md)；活动方案只服务一个待办，并通过该待办的实际 Markdown 链接进入。
- **临时交接材料**：只有具备明确当前承接、入口和退出条件时才能留在活动区；承接成立或任务终止后必须退出。
- **历史材料**：已完成版本、Review、动态结果、被替代方案和退出的手册只由[文档归档索引](../archive/docs/README.md)承接，不再作为当前施工或事实入口。

### 待办与活动方案

同一待办在任何状态最多有一份活动方案，路径为 `docs/方案/<待办ID>-<名称>.md`，且必须由自身待办条目实际链接：

| 待办状态 | 活动方案数量 | 生命周期要求 |
| --- | --- | --- |
| `待确认` | 0 或 1 | 可以只登记未决事项；用户明确保存后允许一份方案，但保存不授权施工 |
| `实施中` | 恰好 1 | 差异已经裁决并按项目协作规则获得实施授权，实施结果按实际发生记录 |
| `待实施` | 0 | 尚无活动施工方案，不用该状态绕过方案保存和实施授权 |
| `暂缓` | 0 | 方案必须退出活动目录和活动入口，待办保留暂缓状态 |

完成、取消或被替代后，待办和方案必须退出活动入口；需要保留历史证据时，完整移动方案并同步登记归档索引。中途门禁或文件写入完成不等于满足完成条件，关闭动作必须遵守已确认方案和[项目协作约束](../AGENTS.md#授权与安全)。

### 检查记录

检查没有可施工问题时，不创建待办或空方案。用户明确要求保存记录时，使用已有 `archive/docs/skills/` 工作与检查记录位置，并由文档归档索引登记；保存的历史记录不成为当前施工入口。

### 收尾与联合复核

每份活动方案按本模板实例化任务值，不复制本节说明，也不把完成条件预写成实际结果：

- 本方案主责与完成证明：
- 关闭时的状态消费者：
- 关联方案、共享文件与对方职责状态：
- 联合只读复核触发条件：
- 验收停点：
- 关闭边界与未运行验证：

没有关联职责时，写明“不适用”及当前依据。关联方案未完成时只能报告本方案主责范围；最后一个关联方案只能触发联合只读复核，不能继承授权、自动关闭或宣称全项目闭环。

方案保存不构成实施授权。用户明确授权按已确认方案实施后，普通任务按[项目协作约束](../AGENTS.md#授权与安全)执行确定变更、列明的普通验证和实际结果记录；完成条件与方案列明的验收要求满足且没有授权差额时，同一次实施授权覆盖待办退出、方案归档、索引更新及最终状态验证。方案明确要求用户验收、出现新的语义决定或高风险动作时，仍在对应停点等待；关闭不推定 commit、push 或 PR。
