# 源文件与恢复清单

本文件记录项目可恢复来源和长期保留资产，避免关键版本只存在于聊天记录、临时目录或失效链接中。

## 1. 当前可信源码

当前可运行源码以 GitHub 仓库 `main` 为准：

```text
https://github.com/kachekakaka/bili_workspace
```

`main` 必须直接包含可审查的 Python、前端、测试、Docker、Windows 脚本和文档，禁止使用 Base64 分片或运行时恢复源码。

重要恢复点应额外保留：

```text
源码 ZIP
完整 Git Bundle
对应提交 SHA（既有历史版本也可记录 tag）
验证记录
SHA256SUMS.txt
```

## 2. 当前 Windows 集成运行资产

Windows x64 运行环境直接以普通 Git 对象保存在：

```text
vendor/windows/python-runtime.pack
vendor/windows/media-runtime.pack
vendor/windows/runtime-manifest.json
```

版本、大小和 SHA-256 的唯一当前真源是 `vendor/windows/runtime-manifest.json`；运维文档不复制这些易漂移值。

运行资产包含：

```text
Portable Python 和锁定依赖
BBDown 1.6.3
FFmpeg
第三方许可证
包内逐文件清单
```

`start.bat` 会调用 `scripts/windows/prepare-runtime.bat`，再由 `scripts/windows/bootstrap-runtime.bat` 校验 manifest schema、pack、路径和内部清单，并解压到被 Git 忽略的 `.runtime/` 与 `BBDown_portable/`。准备器兼容 schema 1 的旧版本字段；新清单和本地状态只写 `runtime_bundle_version`。恢复时不需要复制旧 `.venv` 或旧 `.runtime`。

## 3. 当前运行数据

Windows：

```text
config/      配置和标签定义
userdata/    SQLite、任务、删除历史、索引、日志、缓存和临时状态
downloads/   媒体文件
BBDown_portable/BBDown.data（敏感）
.env（监听地址和端口）
```

Docker 运行宿主机：

```text
CONFIG_DIR
USERDATA_DIR
MEDIA_DIR
```

容器内对应：

```text
/data/config
/data/userdata
/downloads
```

完整恢复必须保留数据库和媒体的一致性。在线复制 SQLite 时同时保留 `.db`、`-wal` 和 `-shm`；具体数据职责和恢复步骤以[备份、恢复与旧版本迁移](备份恢复与V0.4迁移.md)为准，不在本清单重复维护。

## 4. 重要恢复点建议保留

```text
1. 可直接审查的 GitHub main 源码树
2. 对应提交 SHA
3. 源码 ZIP
4. 完整 Git Bundle
5. Windows 集成运行 pack 和清单
6. Windows 完整恢复包
7. Docker 镜像打包说明、离线包及其独立校验和
8. SHA256SUMS.txt
9. 重要变更验证记录
10. 当前需求、设计和字段契约
11. 当前文档与归档索引
```

Git Bundle、Windows 完整恢复包、运行数据备份和 SHA256SUMS 应额外保存到用户自己的 NAS 或云盘；GitHub 不是唯一备份。

## 5. 恢复优先级

1. 从 GitHub `main`、已验证提交或既有历史标签恢复源码；
2. 校验 `vendor/windows/runtime-manifest.json` 并重新生成本地运行目录；
3. 恢复同一时间点的 `config`、`userdata` 和 `downloads`；
4. 恢复敏感的 `BBDown.data`；
5. Windows 先运行 `verify.bat`；Docker 镜像先按[打包与离线交付手册](Docker镜像打包与离线交付.md)核对平台、镜像 ID 和校验和；
6. 运行 `start.bat`；真实 Docker/QNAP 上线按未来另行确认的部署方案执行；
7. 核对作品、标签、删除历史、分组、任务和播放记录。

任何备份或可分发恢复包都必须排除真实登录 Cookie、管理员初始化令牌、未加密密码和用户媒体，除非它本身就是受保护的私人运行数据备份。
