# Windows 启动器继续支持局域网服务器模式

虽然新的 Windows 单文件启动器会复用 `hg_workspace` 的本机运行与构建入口形态，但项目决定不复制其“只监听回环地址、局域网访问只能使用 Docker”的边界。`bili_workspace` 启动器继续承接现有本地模式和局域网服务器模式：默认只监听本机，只有用户显式启用局域网监听后才进入服务器模式，并继续执行管理员认证、可信 Host／代理、安全 Cookie 与 HSTS 等现有安全规则；Docker 仍是 NAS 部署入口，但不是局域网访问的唯一方式。这样避免新的主入口取消现有 Windows 局域网能力，同时不把一次普通启动静默扩大为网络暴露。
