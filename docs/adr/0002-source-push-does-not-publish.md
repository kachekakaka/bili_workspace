# 停止未来正式发布

项目决定停止未来的正式发布：不再通过自动或手动入口创建新的版本 tag、GitHub Release，也不再向 GHCR 推送或更新正式镜像标签。任何分支的源码 push 和普通 CI 只可触发验证或生成短期验证证据；本地构建结果和短期验证产物不因此成为正式发布物。

现有远端 tag、GitHub Release 和 GHCR 镜像作为既有历史状态保留，本决策不授权删除它们。实施阶段必须停用或移除现有正式发布接线；以后若要恢复任何正式发布能力，必须形成新的显式决策并另行取得相应修改与发布授权，不能从源码 push、普通施工或测试授权中推定。

具体收口时，版本专用发布 workflow 退出活动 workflows 并保留为历史材料；Docker workflow 仅保留无 GHCR 登录、无 `packages: write`、`push: false` 的构建验证，同时移除 tag 触发和手动发布输入。这样保留镜像可构建性检查，但活动自动化中不再存在正式发布路径。

由于 GHCR 不再接收后续源码，Docker 新部署默认使用 `BILI_IMAGE=bili-workspace:local` 和 `BUILD_LOCAL=true`，从当前检出源码构建；配置同步继续保留既有 `.env`，因此旧部署必须由维护者显式切换。既有 V0.7.0 GHCR 镜像只作为冻结历史后备，不能代表后续 `main`。
